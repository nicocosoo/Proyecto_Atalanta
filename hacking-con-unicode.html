HACKING CON UNICODE

Daniel Monzón 29/04/2020
Volver a Noticias

Hola a todos, mi nombre es Daniel Monzón y en este primer post me gustaría comentar un tema que he investigado hace poco y que me parece muy interesante. Vamos a hablar sobre Unicode, qué es y cómo usarlo en ejercicios de Red Team o pentests.

¿Qué es Unicode?

Unicode (al contrario de lo que parece) no es un tipo de encoding; es una base de datos que mapea cualquier símbolo (glifo) existente a un número único llamado code point, al cual se le asigna también un nombre único. Por ejemplo, "A" se mapea a U+0041 y "a" se mapea a U+0061.

Existen caracteres Unicode desde U+000000 hasta U+10FFFF (más de un millón de símbolos). Unicode divide todos esos posibles símbolos en «planos»; el más conocido es el BMP (Basic Multilingual Plane), que va desde U+0000 hasta U+FFFF. Existen 16 planos más, denominados «planos astrales».

Unicode se puede usar en JavaScript y la manera de representarlo es con secuencias de escape:

  • Secuencias de escape Unicode (BMP): \u0041\u0042
  • Secuencias de escape ECMA Script 6 (BMP): \u{41}
  • Secuencias de escape ECMA Script 6 (planos astrales): \u{1F4A9}

Los caracteres de los planos astrales también se pueden representar como surrogate pairs en UTF-16. Existe además una feature de Unicode llamada normalización (NFC, NFD, NFKD, NFKC) que «normaliza» algunos code-points para acabar teniendo el mismo carácter.

¿Qué podemos hacer como atacantes con Unicode?

1. Phishing con dominios homoglíficos

Podemos usar herramientas como EvilURL para buscar nombres de dominio parecidos a los que queremos suplantar, generando URLs que visualmente son idénticas al dominio legítimo pero apuntan a otro servidor.

2. Inyecciones SQL

Se puede usar Unicode para bypassear funciones de sanitización custom, aprovechando la normalización de caracteres Unicode. También es posible usar Unicode para terminar strings en MySQL si el charset no es utf8mb4.

3. WAF Bypass

Unicode permite evadir reglas de Web Application Firewalls (WAF) en ataques XSS y otras inyecciones, sustituyendo caracteres ASCII por sus equivalentes Unicode que el WAF no reconoce pero el intérprete sí normaliza.

4. Path Traversal

Unicode puede usarse para conseguir path traversals con restricciones de caracteres, usando codificaciones como %c1%1c o %c0%af en vez de ../, o representaciones hexadecimales de ...

5. Extensiones de archivos

Con el carácter RTLO (U+202E) se pueden «falsificar» extensiones de archivos visualmente, y también es posible bypassear whitelists y blacklists tradicionales con extensiones equivalentes en Unicode.

6. CRLF y Open Redirects

Los caracteres \u2028 y \u2029 pueden usarse de la misma manera que %0a y %0d en inyecciones CRLF y open redirects. Un ejemplo de payload: %E5%98%8A%E5%98%8DSet-Cookie:%20test.

7. Account Takeover

Si sabemos que existe un usuario admin en una aplicación web, registrando un usuario con caracteres Unicode equivalentes podemos sobreescribir sus datos y tomar el control de su cuenta. Incluso es posible bypassear whitelists de dominios en registros o resets de contraseña.

8. Errores de memoria

Muchos programas tienen problemas para manejar caracteres Unicode, lo que da lugar a vulnerabilidades como stack buffer overflow, heap-based overflow, out-of-bounds read/write, integer overflow o use-after-free (UAF). Unicode también incluye caracteres de control, caracteres vacíos (U+2800 y U+200C) y «colisiones» en la conversión de mayúsculas a minúsculas que pueden ser explotadas.

Hay un sinfín de cosas curiosas y útiles que pueden hacerse con Unicode, seguramente muchas más de las que yo he podido encontrar. Espero que os haya gustado. ¡Hasta la próxima!
