Anonimato en la red

Kalitorify

Daniel Tapia 14/12/2020
Volver a Noticias

Actualmente navegar por internet tiene sus riesgos, puesto que nuestra información puede ser accedida por cualquiera con conocimientos informáticos. Por ello los usuarios cada día demandan más privacidad y seguridad en internet. Hoy nos vamos a centrar en una herramienta para Kali Linux que nos ofrecerá un alto nivel de anonimato a la hora de navegar.

¿Qué es Kalitorify?

Kalitorify es un script de Shell para Kali Linux que usa la configuración de iptables para crear un Proxy transparente a través de la red Tor. Con esta herramienta podemos enrutar todo el tráfico de nuestro ordenador a través de la red Tor, sin necesidad de descargar un navegador específico.

Un proxy transparente es un sistema intermediario que se encuentra entre un usuario y un proveedor de contenido. Cuando un usuario realiza una solicitud a un servidor web, el proxy intercepta la solicitud para realizar varias acciones, incluyendo el almacenamiento en caché, la redirección y la autenticación. Con esto configurado, ninguna aplicación podrá revelar su dirección IP real.

Instalación

Primero actualizamos el sistema por completo:

sudo apt-get update && sudo apt-get dist-upgrade -y

Instalamos el servicio Tor necesario para que la aplicación funcione:

sudo apt-get install -y tor curl

Clonamos la aplicación del repositorio oficial:

git clone https://github.com/brainfucksec/kalitorify

Entramos al directorio y completamos la instalación:

cd kalitorify/
sudo make install

Realizamos un reinicio del sistema para aplicar los cambios.

Uso de Kalitorify

Una vez reiniciado el sistema, podemos ver todas las opciones disponibles:

./kalitorify.sh -h

Para poner en marcha la aplicación y enrutar todo el tráfico por Tor:

./kalitorify.sh -t

Todo el tráfico de nuestra red estará enrutándose a través de la red Tor, asignándonos una IP pública y una localización totalmente distintas a las nuestras.

Para detener la aplicación:

./kalitorify -c

Conclusión

Esta sencilla aplicación nos ofrece enrutar todo nuestro tráfico a través de la red Tor sin necesidad de descargar ningún navegador específico. Aplicando lo visto en este artículo junto a un cambio de dirección MAC y hostname, podremos hacer que nuestro equipo y nuestras búsquedas sean casi imposibles de rastrear.
