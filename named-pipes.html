Named Pipes

Daniel Monzón 17/11/2020
Volver a Noticias

En este artículo veremos qué son las Named Pipes y sus posibles usos en el ámbito de la ciberseguridad.

¿Qué es una Named Pipe?

Una Named Pipe es un canal de comunicaciones half-duplex o full-duplex entre un servidor pipe y uno o más clientes. Todas las instancias de una named pipe comparten el mismo nombre, pero cada instancia tiene sus propios búferes y handles, y tienen conductos separados para la comunicación cliente-servidor.

Se usa para IPC (Inter-Process Communication), es decir, para comunicación entre procesos. Existen dos tipos de pipes: las anónimas y las named (con nombre), siendo estas últimas las más útiles a nivel de ciberseguridad.

Todo lo relativo a las named pipes se maneja usando la API Win32 de Windows con funciones como: CreateFile, CreateNamedPipe, CallNamedPipe, ReadFile, WriteFile, ConnectNamedPipe.

¿Qué podemos hacer con las Named Pipes?

Existe una feature de las named pipes que permite al hilo del servidor asumir el access token del cliente que se conecta. Si se tiene el SeImpersonatePrivilege en el access token del servidor de la named pipe, entonces se puede usar ImpersonateNamedPipeClient().

Una de las formas más conocidas de abusar de una named pipe es mediante Meterpreter. Cuando se usa getsystem -t 1, se crea una named pipe (el usuario que la crea debe tener el SeImpersonatePrivilege) y un servicio que al conectarse a esa pipe permite a Meterpreter ejecutarse con el access token de SYSTEM.

Enumeración de Named Pipes

Para enumerar las named pipes disponibles en el sistema se puede usar:

  • PipeList de SysInternals
  • ((Get-ChildItem \\.\pipe\).name) en PowerShell
  • Process Explorer (Ctrl+H) para ver los handles que usa cada proceso

Para verificar si podemos conectarnos a una named pipe con nuestros privilegios actuales, se puede usar accesschk para ver su DACL, o cmdlets de NtObjectManager.

Análisis y debugging

Para analizar y depurar el código de los binarios que crean named pipes, herramientas como dnSpy o IDA Pro son muy útiles. Las named pipes son una superficie de ataque poco explorada pero que puede llevar a vulnerabilidades muy interesantes.
