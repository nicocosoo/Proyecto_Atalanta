Introducción: Hacking con Google Dorks

Por Daniel Tapia & Mouad Tenbihi

Hoy en día todo el mundo utiliza Internet para intentar resolver sus problemas y lo primero que solemos hacer es abrir una pestaña y buscar "google.com". Cuando ponemos en la barra de búsqueda nuestro problema Google nos devuelve muchísima información, pero existe una técnica denominada «Google Hacking» o «Google Dorking» que nos permite llegar a nuestro objetivo de una manera más rápida.

¿Qué es Google Hacking?

Es el uso inteligente e imaginativo de los operadores de Google para buscar vulnerabilidades, fallos de configuración, fugas de información, Zero Days… Con el Google Hacking podemos obtener información valiosa sobre un objetivo en una auditoría, para detectar distintos vectores de ataque o bien para encontrar información que descuidadamente ha sido indexada.

¿Qué podemos llegar a hacer?

Google nos brinda una gran cantidad de operadores de búsqueda. Con ellos podemos buscar:

  • Vulnerabilidades en servidores
  • Directorios y/o mensajes de error que contienen información sensible
  • Documentos y archivos con usuarios y contraseñas
  • Páginas de inicio de sesión, de registro y/o de configuración

Operadores de Búsqueda Básicos

  • –: excluye un término de la búsqueda.
  • +: incluye obligatoriamente el término añadido.
  • OR: permite elegir entre dos opciones.
  • AND: incluye ambos términos buscados.
  • " ": busca el conjunto exacto dentro de las comillas.

Operadores de Búsqueda Avanzados

  • site: Restringe la búsqueda a dominios y subdominios. Ej: site:atalantago.com blog
  • inurl: Muestra páginas que tienen cierta palabra en la URL. Ej: inurl:login.php
  • intitle: Busca palabras en la barra de título. Ej: intitle:hacker
  • filetype: Busca un tipo de archivo concreto. Ej: filetype:pdf hacking

Combinaciones para buscar vulnerabilidades

  • intitle:index.of → listado de directorios
  • intitle:index.of "parent directory" → directorios padre accesibles
  • intitle:index.of.admin → directorios de administrador accesibles
  • filetype:xls user password → archivos xls con usuarios y contraseñas
  • intitle:index.of "server at" → ver versión del servidor

Combinaciones para buscar Data Leaks

  • "twitter" "email" "password" site:pastebin.com → cuentas con contraseñas filtradas

¿Es legal usar Google Hacking?

Sí, es legal usar Google Hacking puesto que todo lo que ofrece es información pública. Lo que pasaría a ser ilegal es hacer uso de las cuentas y contraseñas obtenidas. Si quieres indagar más, existe https://www.exploit-db.com/google-hacking-database, la base de datos de todas estas consultas.

— Daniel Tapia & Mouad Tenbihi —
