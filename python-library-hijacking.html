Python Library Hijacking

Daniel Tapia 01/12/2020
Volver a Noticias

¿Qué es Python Library Hijacking?

El método de explotación de Python Library Hijacking consiste en suplantar una librería de Python que un binario esté usando, para inyectar código de forma que el atacante escale privilegios y/u obtenga una shell en el sistema. Con esta técnica podríamos obtener una escalada de privilegios tanto lateral como vertical, dependiendo de la situación.

Esta explotación se da porque, a la hora de ejecutar librerías en Python, la búsqueda de estas librerías se realiza con un orden de prioridad: primero mira en la ruta donde se ha ejecutado el script y luego sigue un orden de rutas concreto. Si encuentra la librería en la ruta donde se ubica el script, no lo comprueba en el resto de ubicaciones. Es aquí donde el atacante puede aprovecharse.

Procedimiento de explotación

  1. Ubicar el programa objetivo
  2. Listar los permisos de la ubicación en la que se encuentra
  3. Leer el contenido del programa para identificar las librerías que importa
  4. Crear un archivo para suplantar una de las librerías del programa
  5. Inyectar el código deseado (setuid, shell, reverse shell…)

Ejemplo: Reverse Shell con Rshell

Imaginemos un archivo de backup que invoca a librerías de Python. Vamos a suplantar una de ellas creando un archivo con el mismo nombre en el mismo directorio que el archivo a explotar: 

zipfile.py  ← archivo malicioso creado por el atacante

Si el usuario tiene programado un crontab que ejecuta el script de backup cada 5 minutos, cuando se ejecute recibiremos una shell como ese usuario. Este caso es una escalada lateral.

Escalada vertical (root)

Si el proceso se ejecuta con privilegios elevados, podemos inyectar código que establezca nuestro UID al de root (0): 

import os
os.setuid(0)
os.system('/bin/bash')

Esto nos daría acceso completo al sistema. La clave del ataque reside en tener permisos de escritura en el directorio donde se ejecuta el script vulnerable.

Básicamente esto es la explotación de un Library Hijacking. Espero que os haya gustado.
