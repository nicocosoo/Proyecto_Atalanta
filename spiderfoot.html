Spiderfoot

Mouad Tenbihi 09/02/2021
Volver a Noticias

Para hacer un buen pentest es necesario realizar una buena recolección de información del objetivo, o lo que viene a ser una buena fase de information gathering. En este artículo vamos a ver cómo instalar y utilizar una herramienta OSINT automatizada que nos va a permitir recopilar mucha información necesaria para empezar a atacar a nuestro objetivo: Spiderfoot.

Esta herramienta la podemos encontrar tanto en versión web online en spiderfoot.net o de manera local, que será lo que enseñaremos en este artículo.

Instalación

Nos vamos a nuestra máquina de Kali Linux y en una terminal con usuario root clonamos el repositorio:

git clone https://github.com/smicallef/spiderfoot.git

En caso de no tener git instalado:

apt-get install git

Entramos en la carpeta e instalamos los requisitos:

cd spiderfoot/
pip3 install -r requirements.txt

Si no tenemos pip3:

apt-get install pip

Arrancando la aplicación

Una vez instalado, arrancamos con uno de estos comandos:

./sf.py -l 127.0.0.1:5001
python3 sf.py -l 127.0.0.1:5001

Abrimos el navegador y accedemos a 127.0.0.1:5001.

Interfaz de Spiderfoot

New Scan: Aquí daremos un nombre a nuestro proyecto e indicaremos la URL del objetivo. Podemos configurar los módulos y datos requeridos que influirán en el resultado.

Módulos con API Key: Los módulos que aparecen con un candado requieren API Key. Para obtenerlas debemos registrarnos en el sitio web correspondiente. Algunas son gratuitas y otras de pago.

Scans: Aquí se almacenan nuestros escaneos. Disponemos de un filtro de búsqueda, opciones para parar y borrar escaneos, y la posibilidad de descargar los resultados.

Settings: En la configuración podemos añadir las API Keys de los distintos módulos. Seleccionamos el módulo deseado, pegamos la clave obtenida y guardamos con "Save settings".

Conclusión

Spiderfoot es una herramienta OSINT automatizada que nos ayuda a recolectar información de una manera más ordenada y rápida, consiguiendo mejores resultados en nuestras auditorías de seguridad.
